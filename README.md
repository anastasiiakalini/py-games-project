# py-games-project

A Django web application for managing games, developers, genres, and countries.

## Features

- User authentication
- Create and update developers and games
- Browse games, developers, genres, and countries
- Search and filter data
- Pagination
- Custom user model for developers
- Django forms with validation
- Unit tests

## Models

The project includes four main models:

- **Developer** – a custom user who can create and manage games
- **Game** – contains information about a game, including its developer, genres, description, and price
- **Genre** – represents game genres
- **Country** – represents developers' countries
